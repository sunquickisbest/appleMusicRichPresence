# AppleMusicRichPresence
This repository is a plugin for Vencord, Equicord and BetterDiscord to display their current listening activity on discord. It doesn't use the Apple Music API and runs via osascript meaning it also only works for **MacOS** users.

# Note this was only tested on Equicord
To be able to run this plugin, please make sure you have the source version of Equicord and not the prebuilt installers.

To get the source version of Equicord, please see 
https://docs.equicord.org/installing/

To upload the plugins, open your Equicord folder in your terminal and paste these commands.
`cd src`
`mkdir userplugins && cd userplugins`

[!TIP]
If you already have the userplugins folder just paste
`cd userplugins`
Finally run:
`git clone https://github.com/sunquickisbest/appleMusicRichPresence`
